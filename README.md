# 🌾 AgroAI: AI-Powered Crop Disease Detection App
AgroAI is an AI-integrated web application that helps farmers and agricultural professionals 
detect crop diseases through **image uploads** and **AI chat interaction**. The app uses machine 
learning and natural language processing to analyze either uploaded crop images or described symptoms, 
then provides possible disease diagnoses and treatment recommendations.

## 💡 Features
- 🧠 **AI-Powered Diagnosis:** Detects crop diseases using trained ML models from uploaded images.
- 💬 **AgroAI Assistant:** Chatbot that allows users to describe crop symptoms in natural language and receive intelligent responses.
- 🌿 **Recommendations:** Suggests treatment steps, preventive measures, and farming advice.
- ☁️ **Cloud Deployment:** Frontend deployed on Vercel and backend hosted on Render for full functionality.

## 📸 How It Works
1. **Upload an image** of an affected crop leaf to detect the disease automatically.
2. Or **chat with AgroAI** by describing symptoms (e.g., *“my tomato leaves have yellow spots”*).
3. Receive an instant **diagnosis and recommendations**.
