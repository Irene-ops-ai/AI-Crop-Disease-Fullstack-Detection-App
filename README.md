# 🌾 AgroAI: AI-Powered Crop Disease Detection App
AgroAI is an AI-integrated web application that helps farmers and agricultural professionals 
detect crop diseases through **image uploads** and **AI chat interaction**. The app uses machine 
learning and natural language processing to analyze either uploaded crop images or described symptoms, 
then provides possible disease diagnoses and treatment recommendations.
